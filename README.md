# Danendra's Personal Workspace & Portfolio Dashboard 🚀

Welcome to the repository for **Danendra's Personal Workspace**! This project is a highly interactive, modern, and feature-rich portfolio dashboard designed to showcase skills, projects, and professional background in a unique way.

🔗 **Live Demo:** [lat-ukl-danendra-xi-r6.vercel.app](https://lat-ukl-danendra-xi-r6.vercel.app/)

---

## ✨ Key Features

This project isn't just a static portfolio; it's a dynamic workspace designed for an engaging user experience:

- **🏠 Interactive Dashboard**: A central hub featuring a clean, responsive layout.
- **🌞 Smart Greeting & Real-time Clock**: Greets the user based on the current time of day.
- **🎵 Built-in Music Player**: A fully functional music player to listen to Lofi, Synthwave, or Ambient sounds while browsing the site. Features spin animations and progress tracking.
- **📊 Skill Performance & Activity Heatmap**: Visually displays skill proficiencies and a GitHub-style activity heatmap to track progress.
- **🎯 Quick Goals**: A to-do list component to track weekly targets.
- **⌨️ Command Palette**: Quick navigation and actions using a Command Palette (accessible via `Ctrl+K`).
- **📱 Fully Responsive Layout**: Built with a sleek sidebar layout that adapts beautifully to both desktop and mobile screens.
- **📂 Comprehensive Sections**: Includes dedicated pages for Projects, Skills, Gear, Insights, Guestbook, and more.

- **[@google/genai](https://ai.google.dev/)** - Integrated for intelligent, AI-driven features within the application.
- **[@vercel/analytics](https://vercel.com/analytics)** - To gather valuable insights on visitor behavior.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Ensure you have the following installed on your machine:
- [Node.js](https://nodejs.org/en/) (v20 or higher recommended)
- [npm](https://www.npmjs.com/) (or yarn / pnpm)
- [Git](https://git-scm.com/)

### Installation & Setup

**1. Clone the repository**
```bash
git clone <your-github-repository-url>
```
*(Replace `<your-github-repository-url>` with the actual URL of your repository)*

**2. Navigate into the project directory**
```bash
cd demo
```
*(Or whatever the cloned folder is named)*

**3. Install the dependencies**
```bash
npm install
```

**4. Run the development server**
```bash
npm run dev
```

**5. Open the app**
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. The application will automatically redirect you to the main dashboard (`/Main/Dashboard`).

## 💻 Code Structure Overview

- `app/`: Contains the Next.js App Router configuration, layouts, and all the individual pages (Dashboard, Projects, Skills, etc.).
- `Component/`: Reusable React components such as the `sidebar.tsx`, `CommandPalette.tsx`, and music player elements.
- `data/`: Static data files (e.g., `skillsData.ts`, `schools.ts`) used to populate the frontend components.
- `public/`: Static assets like images and fonts.
